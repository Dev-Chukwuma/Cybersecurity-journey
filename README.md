# Purple Team Journey

## Overview

This repository is my unified cybersecurity learning portfolio, bringing together every roadmap and challenge I've worked through on the path to becoming a Purple Teamer — someone who understands both attack (Red Team) and defense (Blue Team), and can bridge the two through detection engineering and continuous improvement.

Rather than keeping each learning track in its own standalone repo, this journey consolidates them into one place so the full picture — offense, defense, and the tools that connect them — lives under a single roof.

## Philosophy

Learn → Practice → Document → Improve

Every module in every track here follows the same discipline: study the concept, get hands-on with it in a lab, document what was learned and found, then carry that forward into the next challenge.

## Structure

This repo is organized into three categories:

### 1. Blue Team

**30 Days of Cybersecurity** — a self-made 30-day challenge covering the defensive side of security: networking fundamentals, Linux/Windows fundamentals, scripting, authentication and cryptography, attack techniques, log analysis, Wireshark, SOC fundamentals, SIEM, incident response, threat intelligence, and MITRE ATT&CK. Status: Complete.

### 2. Red Team

**30 Days of Looting** — a 30-module offensive security journey built on the philosophy "Learn to think like an attacker, so you can defend like a pro." Covers reconnaissance, enumeration, exploitation, privilege escalation, Active Directory attacks, and a full Red Team simulation capstone. Status: In progress — this track will be added to the repo once complete.

### 3. Tools & Specialized Roadmaps

Focused, hands-on roadmaps for specific tools and domains that support both sides of the house:

- **SIEM-Splunk-Learning-Roadmap** — 7 phases, 28 modules covering Splunk fundamentals, SPL, security log analysis, threat detection, SOC dashboards, and incident response, plus 5 practical projects.
- **Wireshark-Learning-Roadmap** — deep-dive into packet analysis and network traffic investigation.
- **Web-Application-and-Pentesting-Roadmap** — offensive web application security and penetration testing fundamentals.
- **Burp-Suite-Learning-Roadmap** — hands-on mastery of Burp Suite for web application testing.

## Why Purple Team?

Blue Team teaches how to detect and respond. Red Team teaches how attackers think and operate. Purple Team is where those two skill sets meet — using offensive knowledge to build sharper detections, and using defensive knowledge to simulate more realistic attacks. This repo exists to document that convergence, one roadmap at a time.
