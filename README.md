# Cybersecurity Journey

## Overview

This repository is my unified cybersecurity learning portfolio. It brings together every roadmap and challenge I work through on my path in security, covering both attack (Red Team) and defense (Blue Team), plus the tools that connect them.

Rather than keeping each learning track in its own standalone repo, this journey consolidates them in one place so the full picture of offense, defense, and tooling lives under a single roof.

## Philosophy

**Learn → Practice → Document → Improve**

Every module in every track follows the same discipline:

- **Learn** the concept
- **Practice** it hands-on in a lab
- **Document** what I learned and found
- **Improve** by carrying it into the next challenge

## Structure

The repo is organized into three categories:

### 1. Blue Team

**30 Days of Cybersecurity** is a self-made 30-day challenge covering the defensive side of security: networking fundamentals, Linux and Windows fundamentals, scripting, authentication and cryptography, attack techniques, log analysis, Wireshark, SOC fundamentals, SIEM, incident response, threat intelligence, and MITRE ATT&CK.

Status: Complete

### 2. Red Team

**Red Team Roadmap** is a 30-module offensive security journey built on the philosophy "Learn to think like an attacker, so you can defend like a pro." It covers reconnaissance, enumeration, exploitation, privilege escalation, Active Directory attacks, and a full Red Team simulation capstone.

Status: Complete

### 3. Tools & Specialized Roadmaps

Focused, hands-on roadmaps for specific tools and domains that support both sides of the house:

- **SIEM-Splunk-Learning-Roadmap**: 7 phases and 28 modules covering Splunk fundamentals, SPL, security log analysis, threat detection, SOC dashboards, and incident response, plus 5 practical projects.
- **Wireshark-Learning-Roadmap**: a deep dive into packet analysis and network traffic investigation.
- **Web-Application-and-Pentesting-Roadmap**: offensive web application security and penetration testing fundamentals.
- **Burp-Suite-Learning-Roadmap**: hands-on mastery of Burp Suite for web application testing.

## Why This Journey?

Defense teaches how to detect and respond. Offense teaches how attackers think and operate. Knowing both makes each side stronger: offensive knowledge builds sharper detections, and defensive knowledge makes attack simulations more realistic.

This repo exists to document that growth, one roadmap at a time.
